문제 20.

운영 중인 쇼핑몰에서 다음 문제가 발생하였다.

특정 쿠폰을 적용하면 결제금액이 음수가 된다.

분석 결과 DiscountService의 공통 할인 로직이 원인이며 다음 기능이 동일 코드를 사용하고 있다.

일반 주문
정기 구독
환불
포인트 결제
제휴사 결제

현재 DiscountService v2.3은 운영 기준 버전이다.

개발자가 수정한 v2.4에서는 일반 주문 문제가 해결되었다.

그러나 테스트 중 환불 금액이 이전과 다르게 계산되는 현상이 발견되었다.

문제
현재 상황에서 v2.4를 바로 운영에 적용해도 되는지 판단하고 이유를 작성하시오.
최초 결함과 수정 후 새롭게 발생한 문제 사이의 관계를 설명하시오.
추가로 확인해야 할 기능과 이유를 작성하시오.
최종 수정본을 운영에 반영하기까지 필요한 기술적·관리적 절차를 순서대로 작성하시오.
최종적으로 남겨야 할 변경 이력 정보를 작성하시오.


일반 주문 결함은 해결되었지만 공통 할인 로직 변경으로 환불 기능에서 새로운 문제가 발생했기 때문에
수정에 따른 부작용이 발생한 상태이다.

일반 주문, 정기 구독, 환불, 포인트 결제, 제휴사 결제 등을 영향 범위에 따라 재시험 해야 한다.

결함 분석 -> 관련 소스 및 호출 기능 확인 -> 영향도 분석 -> 수정안 검토 -> 승인된 변경 수행 -> 관련 기능 재시험
-> 부작용 여부확인 -> 필요 시 재수정 -> 최종 테스트 -> 새로운 버전 부여 -> 형상 검사 -> 운영 반영
-> 변경 상태 보고 및 이력 기록
