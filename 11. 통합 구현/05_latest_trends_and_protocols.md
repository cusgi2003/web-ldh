# 📂 05. 최신 API 동향 및 표준 프로토콜

> **현대적인 웹 환경과 엔터프라이즈 아키텍처에서 활용되는 다양한 연계 기술의 메커니즘과 최신 표준 프로토콜 동향입니다.**

---

## 🔌 1. 연계 기술 및 통신 유형 분류

* **실시간 API:** 필요할 때 즉각적인 답을 주고받는 1:1 대화 방식입니다. 클라이언트가 데이터를 요청하면 중간 매개체 없이 서버가 즉시 응답합니다.
* **메시지 큐 (MQ):** 작업을 차곡차곡 쌓아두는 1:1 번호표 창구 방식입니다. 송신자가 대기열(Queue)에 메시지를 넣으면 수신자가 본인의 처리 속도에 맞춰 꺼내갑니다.
* **이벤트 스트리밍:** 시스템에서 발생하는 모든 상태 변화를 연속적인 데이터 흐름(Stream)으로 취급하여 실시간 수집·분석합니다.
* **`Pub/Sub` (발행/구독):** 메시지를 보내는 쪽(`Publisher`)은 특정 주제(`Topic`)로만 메시지를 내보내고, 해당 주제를 구독 중인 다수의 수신자(`Subscriber`)들에게 메시지가 동시에 전송되는 1:N 통신 구조입니다.

## 🌐 2. 웹 API 패러다임의 변화와 한계 극복

### 🚨 REST API의 구조적 단점과 한계
1. **설계 표준의 한계:** 공식적이고 강제적인 표준 규약이 부족하여 개발자나 기업의 성향마다 아키텍처 설계 방식이 파편화될 수 있습니다.
2. **데이터 전송의 비효율성:** 
   * 클라이언트에게 불필요한 데이터까지 전부 응답으로 보내는 오버페칭(`Over-fetching`) 문제
   * 필요한 데이터를 한 번에 가져오지 못해 여러 번 API를 추가 호출하는 언더페칭(`Under-fetching`) 문제
3. **구조적 제약:** 무상태성(`Stateless`) 특성상 매 요청마다 인증 등의 부가 정보를 중복 전송해야 하므로 통신량이 증가합니다.
4. **메서드의 한계:** `GET`, `POST`, `PUT`, `DELETE`와 같은 제한적인 HTTP 메서드만 사용하므로 복잡한 도메인 연산을 표현하기 까다롭습니다.

### 💡 대안 기술 및 차세대 표준 규격
* **`GraphQL`:** Meta에서 개발한 데이터 쿼리 언어로, 클라이언트가 **자신이 필요한 데이터 구조만 콕 집어서 요청**할 수 있어 REST API의 비효율성(Over/Under-fetching)을 완벽하게 해결합니다.
* **`AsyncAPI`:** 동기식 REST API 명세(OpenAPI)를 이벤트 기반의 비동기/메시징 아키텍처(Kafka, RabbitMQ 등) 영역으로 확장하여 명시한 글로벌 표준 명세서입니다.
* **`오픈 API`:** 기업이나 기관이 내부 데이터 및 핵심 기능을 외부 개발자가 연동·활용할 수 있도록 퍼블릭 환경에 자유롭게 공개한 인터페이스입니다.

## 🛡️ 3. 엔터프라이즈 솔루션 및 보안 인프라

### 🔑 OAuth2 (Open Authorization 2.0)
사용자가 비밀번호를 직접 입력하거나 노출하지 않고도, 제3자 애플리케이션이 사용자의 데이터에 안전하게 접근할 수 있도록 권한을 위임하는 글로벌 표준 보안 프레임워크이며, 현대 **소셜 로그인(Google, Kakao, Apple 등)의 핵심 기반 기술**입니다.

#### 👥 OAuth2의 4가지 핵심 구성 요소 (Roles)
1. **Resource Owner (자원 소유자):** 서비스를 이용하는 실제 **사용자(User)**이자, 계정 데이터의 실제 주인입니다.
2. **Client (클라이언트):** 사용자의 인증 권한을 획득하여 특정 서비스를 제공하려는 **신규 앱 / 웹 서비스**입니다.
3. **Authorization Server (인증 서버):** Resource Owner를 안전하게 인증하고 가용성을 검증한 뒤, Client에게 접근 권한인 **Access Token을 발급**하는 담당 서버입니다.
4. **Resource Server (자원 서버):** 사용자의 프로필, 이메일 등 **실제 데이터(Resource)를 보관**하고 있는 저장소이며, Access Token의 유효성을 검증하여 권한 내 데이터를 Client에 제공합니다.

### 🏢 기업용 대규모 API 관리 및 미들웨어 솔루션
* **`Kong`:** 가볍고 압도적인 응답 속도를 자랑하는 대표적인 클라우드 네이티브 환경 기반의 고성능 API Gateway입니다.
* **`Apigee`:** 구글 클라우드에서 제공하는 엔터프라이즈급 풀스택 API 관리 플랫폼으로, 설계·테스트·보안·모니터링부터 API 수익화까지 전체 생명주기를 통제합니다.
* **`NGINX`:** 대규모 동시 접속 트래픽이 몰리는 환경을 효율적으로 처리하기 위해 고안된 비동기 이벤트 기반의 고성능 웹 서버이자 리버스 프록시입니다.
* **`WSO2`:** 오픈소스 기반으로 통합 API 관리, 식별·인증·인가(Identity), 고도화된 연계 기능을 일체형으로 제공하는 통합 미들웨어 플랫폼입니다.
* **`ISO 20022`:** XML과 JSON 아키텍처를 기반으로 제정된 차세대 글로벌 금융 메시지 교환 표준 규격으로, 전 세계 금융망 간에 데이터 유실 없는 정확한 송수신을 보장합니다.
